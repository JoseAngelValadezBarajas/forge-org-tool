# FORGE Org Tool 0.1.3 Preview 1

Release tag: `v0.1.3-preview.1`

This is the first installable Windows and Android Preview distribution of FORGE Org Tool. The product surface is frozen for this Preview; no new user-facing functionality is included in the release work.

## Platforms

- Windows: SQLite remains available locally and the configured Supabase provider remains available through the existing BYOC flow.
- Android: cloud-only Supabase. The Python sidecar and local SQLite transport are not packaged or silently selected.
- Android release artifacts require the owner's persistent keystore and protected GitHub Actions secrets.
- Windows artifacts are signed only when a valid owner-controlled Authenticode certificate is available. Otherwise the installer is explicitly marked unsigned and the release remains `WINDOWS_SIGNING_PENDING`.

## Known limitations

- This is a Preview, not a store publication or a stability guarantee.
- Android distribution is an APK workflow; Google Play/AAB publication is not automated.
- No automatic updater is included in this Preview.
- Windows SmartScreen reputation depends on the certificate and its publisher history; a valid signature does not guarantee that SmartScreen will show no warning.
- A release workflow never creates a GitHub Release automatically. A human must inspect checksums, signatures and notes before creating the GitHub Pre-release.

## Defect reporting

Open an issue in `JoseAngelValadezBarajas/forge-org-tool` and include:

1. Platform, OS version and Forge version.
2. Installation source and artifact filename.
3. SHA-256 checksum of the downloaded artifact.
4. Reproduction steps and expected/actual behavior.
5. Logs or screenshots with passwords, tokens and personal data removed.

Do not attach keystores, PFX files, passwords, Supabase secrets or real user databases.
