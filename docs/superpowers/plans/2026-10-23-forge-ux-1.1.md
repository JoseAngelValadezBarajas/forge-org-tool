## Working method

Use SPEC → RED → GREEN → REFACTOR → INTEGRATION → VERIFICATION. For each behavior, first add a focused test and observe its expected failure, then implement the smallest feature-owned change and run the focused test before integration checks. Commits should separate coherent slices and must not include unrelated worktree data.
