# FORGE Org Tool specifications

Specifications are authoritative for intended behavior. Each requirement has an identifier, acceptance criteria, and linked executable evidence. M0 and M1 are foundation milestones; Organization/Planning CRUD is explicitly deferred to M2.

## Rules

- Write requirements before implementation.
- Use English for specifications, public contracts, tests, and documentation.
- Keep real legacy data out of this repository.
- Record deviations in an ADR or the milestone traceability document.

## Milestones

- [M0 preservation](M0-preservation/spec.md): preserve the original repository and record a recovery baseline without changing it.
- [M1 foundation](M1-foundation/spec.md): establish the clean public bootstrap, truthful health endpoint, component gallery, boundaries, locks, and quality evidence.
