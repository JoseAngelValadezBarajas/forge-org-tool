# ADR-0001: Public, local-first modular monorepo

**Decision: accepted for M1, 2026-10-20.** FORGE Org Tool is a new, public GitHub repository with independent history and Windows-first local-first architecture. Organizing work is the core domain; repository observation, agent records and delivery evidence remain optional specialized modules. No SaaS/microservices in the first release. The old FORGE project remains available until preservation and compatibility gates pass.
