# Future candidates

Ideas that are not built. None of them is a commitment, and none counts against the active product.

| Candidate                                               | Why it is a candidate                                                                                                                                                                                                 |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Start a project from a template or an existing project  | Figma frame UX-00 / 16. Creating a project is a name and nothing else; an origin (empty, import, template) would make the first minutes useful. Templates must create ordinary records, not a second template system. |
| Assisted migration between Local and Supabase           | Switching provider does not copy data today. A migration needs a preview, a backup and a confirmation before it touches anything.                                                                                     |
| Planning summary per project                            | Counts derived only from recorded planning data (overdue, blocked, without an Epic, in Verify, quiet for two weeks). It must stay manual planning language, never CI-passed or ready.                                 |
| Per-task reminders                                      | Due dates carry no time of day, so reminders are one digest a day. Per-task reminders would need a time on the date and a Windows notification per task.                                                              |
| Reintroducing Readiness, Delivery, Runs or Repositories | Only after real users complete the Today, project, Epic, Done loop on a recurring basis. The retired Figma frames are kept in the design history for that day.                                                        |
